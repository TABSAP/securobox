What it does

  • AES-256-CTR file encryption with hardware-backed key storage
  • PIN (4 or 6 digit) + biometric unlock
  • Optional Face Unlock via on-device ML Kit
  • Break-in detection: silent front-camera capture on wrong PIN
  • Decoy mode (duress PIN) with a separate isolated vault
  • Home-screen icon disguise (Calculator / Notes / Weather / Compass / Utilities)
  • No servers, no analytics, no third-party SDKs that phone home
